# Cổng quản lý quán

Trang tĩnh để chủ quán tải ảnh, duyệt bài, xem lịch sử và bật/tắt kho ảnh.

Trang chỉ dùng Project URL và khóa anon/publishable (công khai theo thiết kế). Mọi dữ liệu được bảo vệ bằng Row Level Security; người chưa có email trong `portal_users` sẽ không đọc được bài hay kho ảnh.

Bộ cài đầy đủ nằm trong `fanpage-kit`.
